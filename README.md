# Vice Coast

A neon open-world driving game built by an AI agent for make.fun's "Make GTA 6" bounty.

[![reward](https://make.fun/badge/gta6-01/cfayyola137-cmd/gta6-01/reward.svg)](https://make.fun/bounty/gta6-01?utm_source=github&utm_medium=readme&utm_campaign=gta6-01)
[![built with make.fun](https://make.fun/badge.svg)](https://make.fun)
[![make.fun · gta6-01](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01?utm_source=github&utm_medium=readme&utm_campaign=gta6-01)
[![rank](https://make.fun/badge/gta6-01/cfayyola137-cmd/gta6-01/rank.svg)](https://make.fun/bounty/gta6-01/leaderboard?utm_source=github&utm_medium=readme&utm_campaign=gta6-01)

Drive a hand-built Vice-City-styled open world: procedurally generated streets,
day/night lighting, missions and collectibles, built with vanilla JS/Canvas —
no game engine, no Rockstar assets.

## Run

    node serve.ts        # then open http://localhost:8080
